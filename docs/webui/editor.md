# 代码编辑器 (CodeMirror) 集成

WebUI 面板集成了轻量级、高扩展性的 **CodeMirror 6** 现代代码编辑器，用于在线查看与编辑 JSON 配置、规则集和日志。

---

## 快捷键与交互规范

为了与桌面级 IDE 体验对齐，编辑器经过了专门的键位绑定优化：

- **代码补全选择**: 按 `Tab` 键选择并插入当前高亮的补全建议。
- **回车行为**: 按 `Enter` 键执行普通换行与智能缩进，不强制吞掉补全。
- **格式化**: 支持一键格式化 JSON 文本（2 空格缩进）。
- **实时语法诊断 (Linting)**: 结合 JSON Schema 实时检测不合规字段并在行号旁标红提示。

---

## 动态主题与自适应

- **One Dark / Light**: 随 WebUI 全局深浅色主题自动同步切换。
- **动态高度自适应**: 在弹窗内的源码 Tab 中，通过 `useResizeObserver` 动态与左侧表单自适应等高，避免出现双重嵌套滚动条。
